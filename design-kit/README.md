# Design Kit

**속도 우선 회색 와이어.** 색·브랜딩·장식 없음.

## 동작만 있으면 됨

| 요소 | 동작 |
|------|------|
| `data-nav` | 화면 전환 |
| `data-modal-open` / `close` | 모달 |
| `data-tab` / `data-tabpanel` | 탭 |
| `select`, `input`, `checkbox` | 브라우저 기본 (추가 JS 불필요) |

## 클래스

`wf-btn`, `wf-card`, `wf-sidebar`, `wf-body`, `table`, `input`, `select` — `packages/renderer/src/shell.ts` 참고.

프롬프트와 shell CSS 클래스 목록은 항상 맞춘다.
