3. 개발 확인 필요사항
개발 확인 1 — 랜딩페이지 자동 호출
동일 광고주의 기존 소재 요청 건에 등록된 랜딩페이지 값을 신규 요청 시 자동으로 불러올 수 있는지 확인 부탁드립니다.

가능: 기본값 자동 노출 + 수정 가능
불가: 랜딩페이지 필수 직접 입력
개발 확인 2 — 레퍼런스 파일 직접 첨부
CRM 소재 요청 단계에서 이미지 또는 영상 파일 자체를 직접 업로드할 수 있는지 확인 부탁드립니다.

가능 시:
링크 첨부 / 파일 첨부 / 없음
불가 시:
파일 첨부 항목을
**브랜드 웍스방 직접 전달**로 변경
개발 확인 3 — 조건부 입력 항목 노출
아래 선택값에 따라 필요한 입력란만 노출되도록 구현 가능한지 확인 부탁드립니다.

4. 추후 ERP 개발 시 참고사항
아래 내용은 이번 CRM 수정 범위에는 포함하지 않으며, 추후 ERP 개발 시 별도 반영이 필요한 사항으로 참고 부탁드립니다.

레퍼런스 파일 확인 방식
추후 ERP에서는 이미지·영상 레퍼런스를 별도로 다운로드하지 않고도
ERP 화면 내에서 바로 이미지 확인 및 영상 재생이 가능하도록 구현이 필요합니다.

해당 부분은 이번 CRM 개선과는 별도 사항으로, 추후 ERP 개발 시 다시 구체화하여 요청드리겠습니다.
