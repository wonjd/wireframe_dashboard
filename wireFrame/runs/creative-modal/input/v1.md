# PRD — 이미지/영상 제작 방식 개선 모달 (CRM)

## 0. 화면 구성 (와이어프레임 산출 단위)
본 개선은 아래 화면/스텝 단위로 각각 독립된 화면을 구성한다.

1. **01-request-list** — 소재 요청 목록 (진입점, '소재 요청' 버튼으로 모달 오픈)
2. **02-step1-type** — 1단계 모달: 콘텐츠 유형 선택 (이미지/영상)
3. **03-step2-common** — 2단계 모달: 공통 정보 입력 (필수항목 + 선택항목)
4. **04-step2-reference** — 2단계 모달: 레퍼런스 전달 방식 분기 (링크/파일/없음)
5. **05-step3-method** — 3단계 모달: 제작방식 선택 (가이드 제작/자유 제작)
6. **06-step4-image-guide** — 4단계 모달: 이미지 + 가이드 제작 (메인·서브 카피)
7. **07-step4-video-guide** — 4단계 모달: 영상 + 가이드 제작 (최종 대본 200자·필수 유지 요소)
8. **08-step4-free-skip** — 4단계 모달: 자유 제작 선택 시 추가 입력 없음(스킵) 상태
9. **09-step5-submit** — 5단계 모달: 입력값 요약 및 제출
10. **10-request-detail** — 요청 상세: 콘텐츠팀 확인 화면 (조건부 항목만 표기, 레퍼런스 미리보기·다운로드)

## 1. 개발 요청사항

### 1-1. 요청 구조
소재 요청은 아래 순서로 진행한다.

**① 콘텐츠 유형 선택** (필수 / 선택형)
- 이미지
- 영상

**② 공통 정보 입력**

필수 (미기입 시 다음 단계 이동 불가)
- 랜딩페이지
- 지면
- 타겟
- 핵심 소구 1순위
- 레퍼런스 전달 방식
  - 링크 첨부
  - 파일 첨부
  - 없음
  - ※ 현재 CRM에서 파일 자체 업로드가 가능한지 확인 필요. 구현 불가 시 아래 개발 확인사항 기준으로 대체.

선택
- 기획의도 / 테스트 목적 (토글 형식 선택)
  - 기존 고성과 소구 확장
  - 탐색 목적 테스트
  - 기타 → 선택 시 수기 작성
- 추가 소구
- 필수 반영사항

**③ 제작방식 선택** (필수 / 선택형)
1. 가이드(대본·카피) 그대로 제작 — 마케팅팀이 전달한 대본·카피·구성 및 가이드를 기준으로 제작한다.
2. 자유 제작(참고용) — 핵심 소구와 타겟을 기준으로 콘텐츠팀에서 자유롭게 기획·제작한다. 전달된 레퍼런스가 있는 경우 참고용으로 활용한다.

**④ 선택값에 따라 추가 입력 항목 노출**

## 2. 유형별 추가 입력 항목

### 2-1. 이미지 요청
① 자유 제작(참고용): 공통 정보 입력 후 요청 가능, 추가 입력 항목 없음

② 가이드(대본·카피) 그대로 제작: 공통 정보 + 아래 항목 추가 입력
- 메인 카피 (필수 / 미기입 시 요청 불가)
- 서브 카피 (선택)

### 2-2. 영상 요청
① 자유 제작(참고용): 공통 정보 입력 후 요청 가능, 대본 입력 없음

② 가이드(대본·카피) 그대로 제작: 공통 정보 + 아래 항목 추가 입력
- 최종 대본 (필수 / 200자 제한 / 미기입 시 요청 불가)
- 필수 유지 문장·요소 (필수 / 미기입 시 요청 불가)

※ 최종 대본은 아이디어 메모나 AI 원문이 아닌, 실제 제작에 사용할 수 있도록 최종 정리된 대본을 입력하는 기준으로 운영한다.

## 3. 개발 확인 필요사항

### 개발 확인 1 — 랜딩페이지 자동 호출
동일 광고주의 기존 소재 요청 건에 등록된 랜딩페이지 값을 신규 요청 시 자동으로 불러올 수 있는지 확인 필요.
- 가능: 기본값 자동 노출 + 수정 가능
- 불가: 랜딩페이지 필수 직접 입력

### 개발 확인 2 — 레퍼런스 파일 직접 첨부
CRM 소재 요청 단계에서 이미지 또는 영상 파일 자체를 직접 업로드할 수 있는지 확인 필요.
- 가능 시: 링크 첨부 / 파일 첨부 / 없음
- 불가 시: 파일 첨부 항목을 '브랜드 웍스방 직접 전달'로 변경

### 개발 확인 3 — 조건부 입력 항목 노출
아래 선택값에 따라 필요한 입력란만 노출되도록 구현 가능한지 확인 필요.

- 콘텐츠 유형: 이미지 / 영상
- 제작방식: 가이드(대본·카피) 그대로 제작 / 자유 제작(참고용)

예시
- 이미지 + 자유 제작 → 공통 항목만 노출
- 이미지 + 가이드 제작 → 메인 카피 / 서브 카피 추가 노출
- 영상 + 자유 제작 → 공통 항목만 노출
- 영상 + 가이드 제작 → 최종 대본 / 필수 유지 문장·요소 추가 노출

## 4. 추후 ERP 개발 시 참고사항
아래 내용은 이번 CRM 수정 범위에 포함하지 않으며, 추후 ERP 개발 시 별도 반영이 필요한 사항이다.

레퍼런스 파일 확인 방식: 추후 ERP에서는 이미지·영상 레퍼런스를 별도로 다운로드하지 않고도 ERP 화면 내에서 바로 이미지 확인 및 영상 재생이 가능하도록 구현이 필요하다. 해당 부분은 이번 CRM 개선과는 별도 사항으로, 추후 ERP 개발 시 다시 구체화하여 요청한다.
