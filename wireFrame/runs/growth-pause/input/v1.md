배경 및 목적
마케터별 소재 요청 방식이 제각각이라 콘텐츠팀이 요청 내용을 재해석하거나 재확인하는 커뮤니케이션 비용이 발생하고 있다. 양식을 늘리는 방향이 아니라, 요청 단계를 구조화해서 입력 편차를 줄이고 제작에 필요한 핵심 정보 누락을 막는 것이 이번 개선의 목적이다.

범위
포함: CRM 소재 제작 요청 양식의 단계형 구조화, 조건부 입력 항목 노출, 랜딩페이지 자동 호출, 레퍼런스 파일 직접 업로드/미리보기/다운로드.
제외: ERP 내 레퍼런스 인라인 확인·영상 재생, 고성과 레퍼런스 장기 보관 기능. (추후 ERP 개발 시 본부장 재논의 후 별도 요구사항으로 정의)

사용자 플로우
1단계 콘텐츠 유형 선택 (필수, 단일선택): 이미지 / 영상
2단계 공통 정보 입력 (필수값 미기입 시 다음 단계 진행 차단)
3단계 제작방식 선택 (필수, 단일선택): 가이드(대본·카피) 그대로 제작 / 자유 제작(참고용)
4단계 1·3단계 선택값에 따른 추가 입력 항목 조건부 노출

유형별 추가 입력 항목 (4단계)
이미지 + 자유 제작(참고용): 추가 입력 없음
이미지 + 가이드 제작: 메인 카피 (필수, 미기입 시 요청 불가) / 서브 카피 (선택)
영상 + 자유 제작(참고용): 추가 입력 없음, 대본 입력 없음
영상 + 가이드 제작: 최종 대본 (필수, 200자 제한, 미기입 시 요청 불가) / 필수 유지 문장·요소 (필수, 미기입 시 요청 불가)
운영 기준: 최종 대본은 아이디어 메모나 AI 원문이 아닌, 실제 제작에 바로 투입 가능한 최종 정리본을 입력한다.

기능 요구사항
FR-1 단계형 요청 구조
필수 항목 미충족 시 다음 단계 이동 버튼 비활성화, 미입력 필드 인라인 에러 표기.

FR-2 랜딩페이지 자동 호출
동일 광고주의 기존 소재 요청 건에 등록된 랜딩페이지 값을 조회 → 중복 제거 → 드롭다운 제공. 사용자가 선택 후 수정 가능. 현재까지 등록된 이력이 없으므로 초기에는 후보가 비어 있으며, 향후 입력되는 값이 누적되어 활용된다. 후보가 없을 경우 직접 입력으로 폴백.

FR-3 레퍼런스 파일 직접 첨부 (개발 가능 확정)

대상: 이미지·영상 파일
용량 제한: 파일 개당 최대 200MB
CRM 내에서 미리보기 및 다운로드 모두 지원
보관 정책: 요청 후 7일간 미리보기·다운로드 가능, 이후 서버에서 자동 삭제
제약 배경: 현 CRM 서버는 저장 공간이 별도 분리되어 있지 않아 확장이 불가하며, 위 용량·보관 정책은 이 제약을 전제로 확정된 값이다.
대체안(불필요): 업로드 구현이 확정되었으므로 "브랜드 웍스방 직접 전달" 대체안은 적용하지 않는다.
FR-4 조건부 입력 항목 노출
콘텐츠 유형 × 제작방식 조합에 따라 5항의 매트릭스대로 필요한 입력란만 노출. 숨겨진 항목의 필수 검증은 비활성 처리하여 제출 차단이 발생하지 않도록 한다.

FR-5 유효성 검증

필수값 검증: 2단계 공통 필수 항목 전체, 조건부 필수 항목
글자 수 제한: 영상 최종 대본 200자
파일 검증: 확장자(이미지·영상), 개당 200MB 초과 시 업로드 거부 및 안내 메시지
비기능 요구사항
스토리지: 7일 만료 기반 자동 삭제 배치 필요 (서버 용량 확장 불가 전제)
미리보기: 이미지 인라인 표시, 영상 재생 지원
배포: 2026-09-02(수) 목표, 개발 및 기본 검증 3영업일
